Proyecto escolar para laura hecho en Python para organizar las notas y los alumnos de un curso. Está armado a pulmón con listas paralelas
y funciones lógicas, sin meter librerías raras ni truquitos.

¿Qué hace el programa?

-Carga de alumnos: Te pide cuántos son (del 1 al 30) y valida que los nombres y las notas de los dos parciales estén bien ingresados 
carácter por carácter.

-Listado completo: Te muestra en pantalla a todos los pibes con sus notas individuales y promedios.

-Estadísticas: Calcula el promedio general del curso, te tira los extremos (el mejor y peor promedio, si hay empates imprime los 2 o los
que sean) y te agrupa quiénes promocionan, aprueban o desaprueban.

-Ranking ordenado: Usa el clásico algoritmo de ordenamiento burbuja sobre una copia de las listas para ordenar a todos del mejor al peor
promedio sin romper el orden original.

-Búsqueda y juegos: Un buscador por nombre y un jueguito que te invierte las letras de un nombre y te cuenta cuántas vocales tiene.

Cómo está armado el código
El proyecto está dividido en tres módulos para que no sea un choclo:
-main_.py: Maneja el menú interactivo con un bucle y un match.
-procesamiento.py: Tiene toda la lógica de los cálculos, las estadísticas y el burbuja.
-validaciones.py: Se encarga de revisar que lo que escribas por teclado no rompa el programa.

¿Cómo se ejecuta?
Tomás si no sabes como ejecutar un programa , veni a cursar con nosotros(comision 313)..
vas a la carpeta donde descargas los archivos , das click derecho y abris la terminal y le tirás este comando: "" python main.py ""
(obviamente tenes que tener descargado python :/ )
